Chrome extension + FastAPI backend

Keep context moving between AI chats without retyping the whole project.

Relay captures visible AI conversation context, cleans it through OpenRouter, stores it in Supabase, and injects the saved context into the next chat.

Flow

Capture once. Reuse everywhere.

01

Capture

Pick up the visible conversation from the active AI site with a page-level save button or the popup.

02

Clean

Send raw chat to the backend, normalize it with OpenRouter, and keep the important structure.

03

Store

Persist the cleaned context in Supabase with per-client dedupe by SHA-256 hash.

04

Inject

Select a saved context and push it into a new chat so the model starts from the right place.

Setup

Local first. Vercel ready.

Build the extension, load the unpacked `dist/` folder in Chrome, and run the backend locally. The landing page itself is static and can be hosted on Vercel from the repo root.
